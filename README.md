# Employee Performance & Attrition Analysis

## Overview
This project analyzes employee performance, satisfaction, and attrition trends using Python, MySQL, SQL, and Power BI. The solution helps organizations understand workforce behavior and support data-driven HR decisions.

## Tools Used
- Python
- MySQL
- Power BI

## Datasets
- Employee Data
- Attrition Data
- Employee Performance Data

## ETL Process
- Extracted data from CSV files using Python.
- Validated duplicates, missing values, and invalid records.
- Transformed and cleaned datasets.
- Loaded data into MySQL Data Warehouse.


## Dashboard Features
- Executive KPI Dashboard
- Attrition Analysis
- Performance Analysis
- Employee Analytics Dashboard
- Interactive slicers and filters

## Outcome
The project provides actionable insights into employee performance, satisfaction, and attrition, helping organizations improve employee retention and workforce productivity.
